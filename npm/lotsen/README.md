# lotsen

Guided tours of Azure DevOps pull requests that Claude Code writes, in a local web UI.

The Claude Code plugin `lotsen@lotsen-hq` starts lotsen through npx, so the plugin is the whole install. Install this
package globally for the `lotsen` commands, such as `lotsen open` and `lotsen restart`:

```sh
npm i -g lotsen
```

lotsen runs on Linux x64 with glibc and on Windows x64. See https://github.com/lotsen-hq/lotsen.
