# Security policy

## Report a vulnerability

Please don't report a security problem in a public issue. Report it privately through GitHub instead: open [Report a vulnerability](https://github.com/lotsen-hq/lotsen/security/advisories/new) on the repository's Security tab. Only the maintainers see the report.

Say what an attacker can do, and how to reproduce it: the Lotsen version (`lotsen --version`), your operating system and the steps.

## Supported versions

Fixes go into the latest release. Lotsen is below 1.0, so an older version gets no fix.
